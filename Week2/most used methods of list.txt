              PYTHON LIST METHODS — SUMMARY
──────────────────────────────────────────────────────────────

📘 What is a List?
   → A list is an ordered, mutable (changeable) collection of items.
   → Defined using square brackets [ ].

   Example:
       l = [1, 2, 3, 4]

   ✅ Ordered
   ✅ Mutable (you can change values)
   ✅ Allows duplicate values

──────────────────────────────────────────────────────────────
🔹 BASIC LIST METHODS
──────────────────────────────────────────────────────────────

1. append(x)
   → Adds an item x to the end of the list.
   Example:
       l = [1, 2, 3]
       l.append(4)
       # Result → [1, 2, 3, 4]

2. extend(iterable)
   → Adds multiple elements (from another list, tuple, etc.) to the end.
   Example:
       l = [1, 2]
       l.extend([3, 4])
       # Result → [1, 2, 3, 4]

3. insert(i, x)
   → Inserts item x at position i.
   Example:
       l = ['a', 'b', 'c']
       l.insert(1, 'z')
       # Result → ['a', 'z', 'b', 'c']

4. remove(x)
   → Removes the first occurrence of item x.
   Example:
       l = [1, 2, 3, 2]
       l.remove(2)
       # Result → [1, 3, 2]

5. pop([i])
   → Removes and returns the item at index i.
     (If no index is given, removes the last item.)
   Example:
       l = [10, 20, 30]
       l.pop()
       # Result → [10, 20]

6. clear()
   → Removes all items from the list.
   Example:
       l = [1, 2, 3]
       l.clear()
       # Result → []

7. index(x, start, end)
   → Returns the index of the first occurrence of x.
   Example:
       l = [5, 10, 15, 10]
       l.index(10)
       # Result → 1

8. count(x)
   → Counts how many times x appears in the list.
   Example:
       l = [2, 4, 4, 4, 6]
       l.count(4)
       # Result → 3

9. sort(key=None, reverse=False)
   → Sorts the list in place (ascending by default).
   Example:
       l = [3, 1, 4, 2]
       l.sort()
       # Result → [1, 2, 3, 4]
       l.sort(reverse=True)
       # Result → [4, 3, 2, 1]

10. reverse()
    → Reverses the elements in place.
    Example:
        l = [1, 2, 3]
        l.reverse()
        # Result → [3, 2, 1]

11. copy()
    → Returns a shallow copy of the list.
    Example:
        l = [1, 2, 3]
        new_list = l.copy()
        # new_list → [1, 2, 3]

──────────────────────────────────────────────────────────────
🔹 COMMON BUILT-IN FUNCTIONS USED WITH LISTS
──────────────────────────────────────────────────────────────

12. len(l)
    → Returns the number of elements in the list.
    Example:
        l = [10, 20, 30]
        len(l)
        # Result → 3

13. max(l)
    → Returns the largest element in the list.
    Example:
        l = [4, 9, 1, 7]
        max(l)
        # Result → 9

14. min(l)
    → Returns the smallest element.
    Example:
        l = [4, 9, 1, 7]
        min(l)
        # Result → 1

15. sum(l)
    → Returns the sum of all numeric elements.
    Example:
        l = [1, 2, 3, 4]
        sum(l)
        # Result → 10

16. sorted(l)
    → Returns a new sorted list (does NOT modify the original list).
    Example:
        l = [3, 1, 4, 2]
        sorted(l)
        # Result → [1, 2, 3, 4]
        # l remains unchanged

──────────────────────────────────────────────────────────────
🔹 OTHER USEFUL OPERATIONS
──────────────────────────────────────────────────────────────

17. list concatenation
    → Join two lists using + operator.
    Example:
        l1 = [1, 2]
        l2 = [3, 4]
        l3 = l1 + l2
        # Result → [1, 2, 3, 4]

18. repetition
    → Repeat elements using * operator.
    Example:
        l = [1, 2]
        l * 3
        # Result → [1, 2, 1, 2, 1, 2]

19. membership test
    → Check if an item exists in a list.
    Example:
        l = ['apple', 'banana', 'cherry']
        'banana' in l
        # Result → True

──────────────────────────────────────────────────────────────
🔹 LIST COMPREHENSIONS (SPECIAL FEATURE)
──────────────────────────────────────────────────────────────

20. List comprehension
    → A concise way to create lists using loops and conditions.
    Example:
        squares = [x**2 for x in range(1, 6)]
        # Result → [1, 4, 9, 16, 25]
