              PYTHON TUPLE METHODS — SUMMARY
──────────────────────────────────────────────────────────────

📘 What is a Tuple?
   → A tuple is an ordered, immutable (unchangeable) collection of items.
   → Defined using parentheses ( ).

   Example:
       t = (1, 2, 3, 4)

   ✅ Ordered
   ✅ Allows duplicate values
   ✅ Immutable (cannot be changed after creation)

──────────────────────────────────────────────────────────────
🔹 BASIC TUPLE METHODS
──────────────────────────────────────────────────────────────

1. count(x)
   → Returns how many times item x appears in the tuple.
   Example:
       t = (1, 2, 2, 3, 2)
       t.count(2)
       # Result → 3

2. index(x, start, end)
   → Returns the index of the first occurrence of item x.
   Example:
       t = (10, 20, 30, 20, 40)
       t.index(20)
       # Result → 1

──────────────────────────────────────────────────────────────
🔹 COMMON BUILT-IN FUNCTIONS USED WITH TUPLES
──────────────────────────────────────────────────────────────

3. len(t)
   → Returns the number of elements in the tuple.
   Example:
       t = ('a', 'b', 'c')
       len(t)
       # Result → 3

4. max(t)
   → Returns the largest item (for numeric or comparable data).
   Example:
       t = (10, 50, 30)
       max(t)
       # Result → 50

5. min(t)
   → Returns the smallest item.
   Example:
       t = (10, 50, 30)
       min(t)
       # Result → 10

6. sum(t)
   → Returns the sum of all numeric items.
   Example:
       t = (1, 2, 3, 4)
       sum(t)
       # Result → 10

7. sorted(t)
   → Returns a sorted list (does NOT modify the tuple itself).
   Example:
       t = (5, 2, 8, 1)
       sorted(t)
       # Result → [1, 2, 5, 8]

──────────────────────────────────────────────────────────────
🔹 OTHER USEFUL OPERATIONS
──────────────────────────────────────────────────────────────

8. tuple concatenation
   → You can join two tuples using + operator.
   Example:
       t1 = (1, 2)
       t2 = (3, 4)
       t3 = t1 + t2
       # Result → (1, 2, 3, 4)

9. repetition
   → Repeat elements using * operator.
   Example:
       t = (1, 2)
       t * 3
       # Result → (1, 2, 1, 2, 1, 2)

10. membership test
    → Check if an item exists in a tuple.
    Example:
        t = ('apple', 'banana', 'cherry')
        'banana' in t
        # Result → True

──────────────────────────────────────────────────────────────
🔹 CONVERSION BETWEEN LIST AND TUPLE
──────────────────────────────────────────────────────────────

11. list() — convert tuple to list
    Example:
        t = (1, 2, 3)
        l = list(t)
        # Result → [1, 2, 3]

12. tuple() — convert list to tuple
    Example:
        l = [4, 5, 6]
        t = tuple(l)
        # Result → (4, 5, 6)

──────────────────────────────────────────────────────────────
🔹 IMMUTABILITY REMINDER
──────────────────────────────────────────────────────────────
Tuples are immutable — you cannot:
   ❌ Add elements
   ❌ Remove elements
   ❌ Modify elements

Example:
    t = (1, 2, 3)
    t[0] = 10
    # ❌ Error → TypeError: 'tuple' object does not support item assignment
